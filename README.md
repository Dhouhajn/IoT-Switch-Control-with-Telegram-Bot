# IoT-Switch-Control-with-Telegram-Bot
Ce projet Node-RED implémente un système de communication bidirectionnelle entre une application IoT et les utilisateurs via Telegram Bot.

## Schéma du Flux
[Inject ON] → [Telegram Switch] → [Switch] → [Telegram Notify] → [Debug]
     ↓                                           ↑
[Inject OFF]------------------------------------|
